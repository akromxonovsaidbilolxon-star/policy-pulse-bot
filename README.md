# Policy Pulse Fleet Bot

An automated Telegram bot designed to track truck and driver movements (`PICKUP`, `DROPOFF`, `SWAP`) with real-time Google Sheets integration via a Google Apps Script Web App.

## Environment Variables
To ensure proper operation on Railway, add the following variables in your project settings:
- `TELEGRAM_BOT_TOKEN` — Your Telegram bot token.
- `GOOGLE_SCRIPT_URL` — The URL of your deployed Google Apps Script web application.
